# Old Akkadian localization policy

The `akk` locale uses a readable scholarly Latin transliteration. It follows Old
Akkadian spelling and morphology where the source material permits, including
case endings and mimation. Cuneiform is not used because a single normalized UI
term can have several period- and context-dependent sign spellings.

Modern software and finance concepts are expressed as semantic compounds made
from ancient words. The compounds are intentionally transparent neologisms;
they do not claim that the complete modern phrase is attested in an ancient
text.

| Modern concept | Akkadian rendering | Semantic image |
| --- | --- | --- |
| wallet | `bīt kaspim` | house of silver/money |
| account | `nikkassum` | reckoning/account |
| network | `ḫarrānum` | road or journey |
| node | `bābum` | gate |
| transaction | `tērtum` | instruction, report, or dispatched matter |
| hash | `kunukkum` | seal or sealed mark |
| block | `libittum` | brick |
| blockchain | `ṣerret libittim` | chain of bricks |
| backup | `ṭuppum šanûm` | second tablet |
| password | `awāt pītim` | word of opening |
| passphrase | `ṣerret awātim` | chain of words |
| seed | `zēr niṣirtim` | seed of the secret |
| liquidity | `mê kaspim` | waters of silver/money |
| liquidity pool | `būrtum` | well |
| decentralized | `lā bēlim` | without a single lord |
| email | `ṭuppum ša šamêm` | tablet of the heavens |
| smartphone | `ṭuppum qātim` | hand-tablet |
| vote | `ṭēmum` | considered decision or counsel |
| curve | `qaštum` | bow, used as the image of a curve |

Names, ticker symbols, standards, formulas, and protocol identifiers remain
literal when changing them would make the product unsafe or ambiguous: SORA,
Polkaswap, XOR, QR, PIN, IBAN, JSON, URL, TBC, XYK, and `x*y=k` are examples.
