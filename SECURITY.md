# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities in SORA Wallet Android privately to
**takemiya@soramitsu.co.jp**. The security contact is Makoto Takemiya
([@takemiyamakoto](https://github.com/takemiyamakoto)). This contact covers
this repository, including the active `modernize` branch.

Include the affected source revision or app version, reproduction steps,
expected and observed behavior, and the potential security impact. Use
synthetic accounts and keys in examples. Never send real seed phrases,
private keys, backup passwords, or customer data.

Please do not publish details of an unpatched vulnerability in public issues
or pull requests. Use the private contact above to coordinate a fix and
disclosure.
